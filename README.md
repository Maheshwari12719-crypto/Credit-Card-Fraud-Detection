# Credit Card Fraud Detection

## Project Overview
This project analyzes credit card transactions and uses machine learning to detect potentially fraudulent transactions.

## Dataset
The dataset contains anonymized credit card transaction features with a target variable `Class`:
- 0 = Genuine transaction
- 1 = Fraudulent transaction

The raw dataset is not uploaded to GitHub because it exceeds GitHub's file-size limit.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Model Evaluation
The model was evaluated using:
- Confusion Matrix
- Precision
- Recall
- F1-Score
- ROC-AUC

## Results
ROC-AUC: 0.9721

The project focuses on detecting fraudulent transactions in a highly imbalanced dataset.

## Files
- `fraud_detection.py` — Python machine learning implementation
- `.gitignore` — prevents the large raw dataset from being uploaded
